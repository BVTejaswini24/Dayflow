## 📖 About

**DayFlow HRMS** is a full-stack Human Resource Management System designed to simplify and centralize everyday HR operations.

The platform provides dedicated experiences for **administrators and employees**, making it easier to manage employee information, attendance, leave requests, payroll details, and workforce activities from a single application.

The project focuses on providing a **clean, responsive, and intuitive user experience** while keeping common HR workflows simple and efficient.
